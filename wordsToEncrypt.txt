This program uses the mpi4py library, which provides MPI support for Python. It reads a text file and splits the contents into equal parts according to the number of available MPI processes. These chunks are then distributed using comm.scatter(), allowing each process to handle a portion of the text. Each process applies Caesar cipher encryption (a fixed shift of characters, e.g., +3) to its chunk. Once encrypted, the data is gathered back to the root process using comm.gather(), which combines all pieces into the final result and writes it to a new output file. The program also measures execution time using MPI.Wtime() to assess performance.
